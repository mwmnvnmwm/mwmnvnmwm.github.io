# 刘志恒 · 游戏交互设计作品集

中文个人作品集：五个游戏项目、交互设计案例与完整文字简历。

公开联系方式：175939466@qq.com。

此仓库只包含经批准的网站部署包及 GitHub Pages 工作流。作品原稿和内部工作资料不在仓库中。

部署包采用小文件分块，以便在不稳定的网络下上传和重试。GitHub Actions 按清单验证每块及完整 ZIP 的 SHA-256，解压已构建的网站，再发布到 GitHub Pages；访问网站不需要下载这些分块。

## 部署

在仓库 Settings → Pages 中选择 GitHub Actions。推送到 main 或手动运行 Publish portfolio to GitHub Pages 工作流即可部署。

Actions 版本依据 [GitHub 官方自定义 Pages 工作流文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。
